Glyph Editor

For glyphs with frames, use the Glyph Animator.

Draw on the canvas, or open site/js/mods/glyphs.js to edit the mod glyphs.

Pick a tool in the bar, or press its key. Press ? for all the shortcuts. The size list changes the size of the drawing. Its pixels stay at the top left.

Fills
Preview

1x, 2x and 3x, in the light and the dark theme.

Device format

The frame is its columns, left to right. Each column is one 32-bit big-endian word, with the top row in the most significant bit. A frame taller than 32 rows uses more words for each column. Import uses the size of the canvas.

Rows

Type or paste the rows: # is lit and . is dark. Rows of the canvas's size apply as you type. Apply rows puts rows of another size at the top left.
