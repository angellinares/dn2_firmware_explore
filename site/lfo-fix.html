LFO ONE/HALF Fix

In TRIG MODE ONE, an LFO should run one cycle and then stop. In HALF, it should run half a cycle and then stop. The factory firmware gets both parts wrong. It stops at fixed points of the cycle, and does not count from the start phase. So with SPH moved, the LFO ends early (or, in HALF, late). And when it stops, it jumps to the centre: a square on the filter “turns off” or “jumps back to the middle”.

This mod fixes both, on audio and MIDI tracks. Select your firmware file. Then download a signed image.

Make sure that you can go back to stock before you flash a modified file. The Early Start-up Menu flashes the stock firmware over MIDI. Do this one time with the stock file, before you flash a modified file. Back up your +Drive. No tool here can recover it.

What changes

Length
ONE runs one whole cycle from the start phase, HALF half a cycle, whatever SPH is and in either speed direction. Factory: ONE from SPH 96 plays a quarter of a cycle, HALF from SPH 64 a whole one
Hold
When it stops, the LFO stays at the value it reached instead of jumping to the centre. A square on the filter in ONE ends closed and stays closed. In HALF, the square stays open. A triangle in HALF stays at its peak
Where
Audio tracks’ LFOs and MIDI tracks’ LFOs, which the firmware runs through two separate copies of the same code
Unchanged
FREE, TRIG and HOLD. TRIG still starts at SPH. The random waveform does not change: its SPH is SLEW. A retrig from the TRIG page does not change: it restarts the LFO for a full run. The waveforms that New LFO waveforms adds do not change: their SPH has a different meaning
Why
The firmware tests for “the middle” and “the end” of the cycle, not for “half a cycle / a cycle since the trig”. To stop, it writes a fixed value per waveform into the output. The fix counts the cycle from the start phase. It starts the LFO at zero, and adds the start phase back when it reads the waveform. The fix also removes those writes

—

Tested. The hold on audio tracks passed on a Digitone II on 2026-10-08, against factory 1.11 on the same patch. That was the first version of this fix (LFO hold, now superseded).

For the length and the MIDI tracks, the emulator compared factory with fixed over every mode, waveform, start phase, speed direction, fade and retrig pattern. Only ONE and HALF change. They now trace the free-running waveform until they stop.

On the instrument (2026-10-09, audio track), ONE and HALF run their full length from SPH 0 to 120, with 74, 85, 100 and 120 among them. They hold the value they reached, with no click or flip at the end.
