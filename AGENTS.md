# Agents

An agent that works on this repository follows [CONTRIBUTING.md](CONTRIBUTING.md). It holds the house
rules: the design issue first, what a PR contains, images, tests, writing and licences.

- Never push to `main`. Open a pull request. The repository owner merges.
- Run `pytest -m "not slow"` before you open a PR.
- Never flash an instrument. The owner runs the tests on the instrument.
